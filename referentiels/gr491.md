# GR491 : Guide de référence de conception responsable de services numériques (INR)

Source : https://gr491.isit-europe.org/. Le guide complet compte 8 familles,
61 recommandations et 516 critères.

**Extraction partielle, assumée** : ce fichier reprend **47 recommandations sur 61**,
dans **6 familles sur 8**, au niveau recommandation (extraction du 17/07/2026). Les deux
familles absentes, Stratégie et Spécifications, relèvent de la revue de cadrage plus que
de la génération de code : voir la section qui leur est consacrée en fin de fichier. Les
critères détaillés de chaque recommandation sont consultables sur le site par famille
(`?famille=frontend`, etc.).

Les identifiants ci-dessous sont cités dans les règles `.continue/rules/` pour tracer
chaque consigne vers sa source.
